ARQUITETURA DEFINITIVA

Como colocar o jogo online no Netlify (Grátis)

Guia de 3 passos para publicar seu WG permanentemente sem depender de planos pagos.

1

Banco Supabase

Crie um projeto no Supabase (grátis), vá no SQL Editor e execute o arquivo schema.sql gerado no pacote. Suas 8 tabelas serão criadas instantaneamente.

2

Repositório GitHub

Crie um repositório no GitHub (ex: wg-mundo-ninja) e suba os arquivos do pacote zip.

3

Deploy no Netlify

No Netlify, clique em "Import from GitHub". Em 30 segundos ele gera o link online definitivo para os seus jogadores acessarem de qualquer celular ou computador!
